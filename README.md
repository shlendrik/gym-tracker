# Gym Tracker — Telegram Mini App

React + TypeScript + Vite, данные хранятся в localStorage.

## Запуск

```bash
npm install
npm run dev      # локальная разработка (откроется и в обычном браузере)
npm test         # unit-тесты
npm run build    # сборка в папку dist
```

## Деплой

Каждый push в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`):
тесты, сборка и публикация на GitHub Pages. Адрес сайта: `https://<аккаунт>.github.io/gym-tracker/`.
Этот адрес указывается в BotFather как URL Mini App. Токен бота в репозитории не хранится и приложению не нужен.

## Что готово

- **Тренировка:** упражнения из библиотеки (41 шт.) и свои, подходы (вес × повторы), подстановка значений с прошлой тренировки, тоннаж и таймер, черновик переживает перезапуск. Кнопка «Завершить тренировку» всегда на виду.
- **Экран «Тренировка сохранена»:** итоги и кнопка «Сохранить как план».
- **Планы:** конструктор (название, упражнения, подходы и повторы, порядок), редактирование, удаление, запуск тренировки по плану (вес подтягивается с прошлой тренировки).
- **История:** список тренировок, подробности по подходам, удаление.
- Тема Telegram (светлая/тёмная), проверено на экранах 320–390 px.
