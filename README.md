# Gym Tracker — Telegram Mini App

React + TypeScript + Vite, данные хранятся в localStorage.

## Запуск

```bash
npm install
npm run dev      # локальная разработка (откроется и в обычном браузере)
npm test         # unit-тесты
npm run build    # сборка в папку dist
```

## Деплой

Каждый push в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`):
тесты, сборка и публикация на GitHub Pages. Адрес сайта: `https://<аккаунт>.github.io/gym-tracker/`.
Этот адрес указывается в BotFather как URL Mini App. Токен бота в репозитории не хранится и приложению не нужен.

## Что готово (этапы 1–3)

- Каркас, тема Telegram (светлая/тёмная), нижняя навигация, обёртка над WebApp API с фолбэком для браузера
- Слой данных: типы, хранилище с версией схемы, библиотека из 41 упражнения, свои упражнения
- Активная тренировка: подходы (вес × повторы), подстановка значений с прошлой тренировки, черновик переживает перезапуск, тоннаж и таймер в реальном времени, завершение через нативную MainButton

## Структура

```
src/
  storage/   абстракция хранилища (localStorage, позже CloudStorage)
  store/     zustand-хранилища: workouts, templates, exercises, active
  domain/    чистые функции: тоннаж, 1RM, история (с тестами)
  data/      базовая библиотека упражнений
  telegram/  обёртка над Telegram WebApp API
  ui/        общие компоненты
  pages/     экраны
```
